إمتى النصيحة بتظهر؟

3 نصايح بالكتير في الورديةوبين كل نصيحة والتانية 20 دقيقة على الأقل. مش بتظهر وإنت فاتح نموذج أو بتحصّل.
حسب اللي بيحصل قدامك الأولمثلاً: دكتور «وصل» ومش مربوط بعيادة ← تظهر «اربط الدكتور بالعيادة». مريض حضر وعليه فلوس ← «حصّل قبل ما يمشي».
«فهمت» / «فكّرني بعدين» / «ما تورينيش دي تاني»«فهمت» بتعلّمها اتعلّمت. «بعدين» بترجع بعد ساعتين. «تاني لأ» بتخفيها خالص.
«جرّبها دلوقتي» و«كمّل اتعلّم ▶»الأول بيفتحلك الشاشة الحقيقية، والتاني بيشغّل الفيديو بتاعها لو موجود. ولو لسه معملناهوش بيتكتب «الفيديو جاي قريب».
