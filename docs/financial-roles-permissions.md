# الأدوار المالية وصلاحيات الأقسام

- الدوران الجديدان: accountant (محاسب)، financial_manager (مدير مالي).
- دور مالي بدون أدوار إدارية لا يمنح الحسابات أو جهات التعاقد أو المهام تلقائيًا.
- في لوحة التحكم، أضف الحساب أو غيّر دوره، ثم افتح «صلاحيات الأقسام» بجانب الحساب.
- يحدد السوبر أدمن العرض والإضافة والتعديل والحذف لكل حساب. العرض شرط لبقية الإجراءات.
- الإضافة في الحسابات تشمل المستلزمات والخدمات والباقات، وفي التعاقدات تشمل الجهات والعقود وبيانات المتابعة والربط.
- التعديل في التعاقدات يشمل العقد ورفع/استبدال ملفه. الحذف يحافظ على منع حذف جهة مرتبطة بمرضى أو زيارات.
- المهام تتبع نطاق إسناد الموظف أو إدارته للمشروع. الإضافة تسمح بإنشاء مشروع، وإضافة مهام في المشروع الذي يديره. التعديل يشمل العمل على مهامه أو المراجعة والتعديل داخل مشروع يديره. الحذف غير متاح في نظام المهام الحالي.
- الأدوار العامة super_admin وgeneral_manager تحتفظ بصلاحياتها الحالية. صلاحيات هذه الشاشة لا تقلص صلاحيات حساب يحمل أحد هذين الدورين.
- الأدوار الأخرى تبقى كما كانت. لا يتغير تسجيل الدخول أو بيانات أي حساب.

## التفعيل

1. شغّل `supabase/migrations/202610130002_financial_roles_permissions.sql` في SQL Editor داخل مشروع إنتاج المحتوى `uuijfbpgvtdxgaosqpxo`. الملف يحتاج إعداد جهات التعاقد والمهام الموجودين. يعاد تشغيله دون مسح البيانات أو الصلاحيات المحفوظة.
2. حدّث الداشبورد، واختر الدورين والصلاحيات من لوحة التحكم. الموظف يحدّث صفحته بعد حفظ صلاحياته. قاعدة البيانات تفرض الإلغاء فورًا حتى لو كانت واجهته قديمة.
3. لرفع ملفات العقود بالحسابات المالية، انشر مصدر `supabase/functions/contracting-entity-contract-upload/index.ts` المحدّث في وظيفة Supabase بنفس الاسم. لا تضف أو تغيّر مفاتيح سرية لهذه الإضافة.

ملف الأدوار يدعم وجود إعداد التكرار قبل تفعيله أو بعده. تحديث التكرار نفسه يحافظ على فحص الصلاحيات، ولا يستبدل إعدادها إذا كانت موجودة. تظل جدولة التكرار الموجودة مستقلة، ولا ينشئ ملف الأدوار وظيفة جدولة أخرى.

## ما تم اختباره

- PostgreSQL محلي عبر PGlite: RLS وRPC، الفروع الثلاثة، المنع الافتراضي، فصل الإجراءات، منع منح النفس صلاحيات، عزل المهام، إلغاء الصلاحية وإعادة التفعيل.
- تثبيت صلاحيات المالية قبل إعداد التكرار وبعده، مع الحفاظ على حقول التكرار وتعديل المهمة.
- JSDOM: أسماء الأدوار، قائمة منح الصلاحيات، إخفاء الإجراءات الممنوعة وحدود نطاق المهام.
- مصادقة رفع العقد بمحاكاة، بدون رفع ملفات أو طلبات توليد.
- لم تُنفذ تغييرات على Supabase الحي ولم تُجرَّب حسابات الموظفين الحقيقية هنا.
