# ترتيب واجهة المخزن

خمسة أقسام رئيسية. كل قسم يعرض أزرار أقسامه الفرعية فقط حتى يختار المستخدم أحدها. لا تُجمع النماذج والجداول كلها في صفحة واحدة.

| القسم | الشاشات |
| --- | --- |
| الرئيسية | المؤشرات والتنبيهات وملخص المخزون |
| المخزون | الأصناف والأسعار، الأرصدة حسب المكان |
| العمليات | التوريد والطلبات، التحويلات، الصرف والاستهلاك، البيع والتحصيل |
| الجرد | جلسات ومواعيد الجرد، رفع Excel والإدخال الفردي |
| التقارير | تقارير الاستهلاك، سجل الحركات |

الموردون من داخل شاشة التوريد والطلبات. الفروع والمخازن والمسؤوليات من زر «إدارة الفروع والمخازن» بجوار اختيار المكان.

التنقل محلي بين الشاشات المحملة، وكروت المؤشرات تفتح الشاشة المطلوبة وتحدد قسمها الرئيسي. تغيير المخزن يحتفظ بالشاشة المختارة ويحمّل بيانات المكان المحدد. صلاحيات الشاشات لم تتغير، ومنها إخفاء تقارير الاستهلاك وإدارة الموردين للحساب الذي لا يملك صلاحية إدارة المخزن.

هذا تحديث واجهة فقط، ولا يتطلب SQL جديداً. اختبارات الواجهة تغطي التنقل على الكمبيوتر والموبايل، والموافقة والتوريد والهالك والموردين، والتحويلات والجرد والإدخال الفردي وإدارة الفروع.
