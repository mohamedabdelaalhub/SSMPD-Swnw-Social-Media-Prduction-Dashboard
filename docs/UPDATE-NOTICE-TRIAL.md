# تجربة تنبيهات التحديث

تطوير تدريجي للتنبيه القائم، وليس إطلاق كاش عام أو وضع offline. الواجهة لا تنفذ refresh تلقائيًا بسبب الحدث.

تستخدم التجربة اشتراكات المحتوى والتعليقات والليدز الموجودة، وتغيّر نتائج صندوق الإشعارات الشخصي الموجود. لا نضيف اشتراكًا أو جدولًا أو استعلامًا أو polling. حدث في قسم غير مفتوح لا يزعج المستخدم، وعند فتح القسم تحمل واجهته البيانات كالمعتاد. ضوابط RLS الحالية ومراجعة صلاحية التاب تمنع توسيع الوصول. التنبيه لا يعرض عنوان السجل أو تفاصيله.

الأحداث المتقاربة تظهر في تنبيه واحد. تحديث القسم يعيد رسم القسم الحالي فقط بالمسار السابق، ويحاول الحفاظ على التمرير. النافذة المفتوحة تمنع التحديث، والمدخلات المعدلة تتطلب تأكيد المستخدم قبل الاستبدال. لاحقًا يغلق التنبيه دون تغيير الشاشة. لا نستدعي location.reload ولا نحول التنبيه لإقرار تعارض سجل أو حماية من lost updates؛ فحص تعارض الكتابة يظل مسؤولية كل موديول وخادمه.

## إيقاف التجربة

زر «تجربة تنبيهات التحديث» في الرئيسية الشخصية يوقفها أو يشغلها للحساب الحالي في جلسة المتصفح، ويعيد سلوك التنبيه السابق عند الإيقاف. لا تُحفظ بيانات السجلات، فقط تفضيل on/off مرتبط بمعرف الحساب في sessionStorage.

الإيقاف العام من config.js عبر updateNoticeTrial:false مع رفع بصمة config. الرجوع الكامل يكون بعكس commit التجربة. لا توجد migration تحتاج rollback.

## نطاق التجربة

- المحتوى والتعليقات في أقسام المحتوى ذات الصلة والرئيسية.
- الليدز داخل قسم الليدز.
- تغيّر صندوق الإشعارات الشخصي في الرئيسية والمهام وأدائي.
- تلغي التجربة إعادة رسم الرئيسية بالكامل عند وصول إشعار جديد، مع استمرار عدادات الإشعارات وتفاصيلها الحالية.

لا نعد بأن كل تغيير مالي أو مخزني أو كل حجز جديد يولد حدثًا بهذه التجربة. الموديولات غير المشمولة تحتفظ بسلوكها القائم، ومنها تحديث المهام الدوري. لا كشف تلقائيًا عن إصدار كود جديد. توسيع المصادر وفحص التعارض وكاش البيانات خطوات مستقلة بعد تقييم التجربة.

اختبارات tests/update-notice-trial-dom.cjs وtest/refresh-preservation.cjs تغطي تجميع الأحداث، الصلاحيات، الحفاظ على المسودة، رفض التحديث وسط نافذة، التأكيد والإلغاء، والإيقاف والرجوع للسلوك السابق. tests/update-notice-trial-fixture.html محاكاة مستقلة دون بيانات أو كتابة حقيقية.

## تنظيم إعدادات المستخدم

إعداد الصوت وتنبيهات التحديث أصبحا صفين بأسماء ومفاتيح تشغيل في نافذة «إعداداتي» بالرئيسية. نقل تغيير الصورة إلى النافذة، مع بقاء الصورة بجانب الاسم في الهيدر. تحديث الرئيسية أيقونة 44px لها اسم وصول وتلميح. لا تُحمل الصورة الإضافية للإعدادات إلا عند فتح النافذة، وتشارك الكاش والطلب القائمين. إغلاق الإعدادات قبل فتح نموذج رفع الصورة يمنع اختباء نموذج الرفع تحت dialog الأصلية. هذا تعديل عرض وتنظيم دون تغيير نطاق التجربة أو الصلاحيات أو تخزين البيانات.
