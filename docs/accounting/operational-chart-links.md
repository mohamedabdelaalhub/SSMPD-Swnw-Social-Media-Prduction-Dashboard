# ربط حسابات التشغيل بشجرة المحاسب

حسابات التشغيل الخمسون أصبحت حسابات حركة تحت مجموعات شجرة المحاسب. بقيت أكوادها وقواعد ترحيلها وقيودها كما هي. هذا ربط هرمي للحساب الرقابي، وليس استبدال كود العملية بكود حساب تفصيلي يحمل اسم طبيب أو مورد. لم تُدمج الأرصدة مع حسابات الأشخاص لمجرد تشابه الاسم.

يحدد operational-chart-links.json الأب لكل حساب. مثلًا 5211 تحت 050501 للمرتبات العامة، و2131 تحت 020104 للمستحقات، و2111 تحت 02010101 لذمم الموردين، و5218 تحت 050512 للمصروفات البنكية. يظهر إجمالي الفرع في الشجرة من الحسابات التابعة مرة واحدة. حساب النقد القديم1111 يتبع الصناديق برصيد محفوظ، والخزن المربوطة تستمر بحساباتها المستقلة.

الحسابات العامة المختلطة مثل مخزون الأدوية والمستلزمات وإيراد الخدمات تبقى تحت مجموعة مشتركة، دون افتراض تخصص أو اسم جهة. مجمع الإهلاك1291 بقي أصلًا مقابلًا سالبًا تحت الأصول الثابتة، ولم يتحول إلى التزام بسبب تسمية مجموعة في Excel. لا تعديل لنوع الحساب أو إشارات مبالغه.

تطبق scripts/link-operational-chart.sql الإعداد عبر public.clinic_finance_ledger_command وتدقيقها القائم تحت مستخدم مدير مالي مفعّل. تتحقق من مخزون50 حسابًا، وتطابق النوع وقابلية الأب للتجميع والمستويات، وتقارن كل سطور القيود قبل وبعد. لا تنشئ قيودًا. إعادة التنفيذ تتخطى الروابط المتطابقة.

التحقق

- operational-chart-links.cjs يشغّل دوال المرتبات والخصومات وصرف الصافي بعد الربط، ويتحقق من منع استقبال تعديل الحسابات والمستويات واتزان القيود.
- operational-chart-live-rollback.sql يختبر الإنتاج بهويات مصادقة داخل معاملة تتراجع بالكامل. يستخدم سعر المخزون الحالي من snapshot كي يراعي إعداد هامش الربح. يشمل الشراء والمورد والفاتورة والمقدم والتحصيل والتسوية والمرتبات والأصل والإهلاك. نجح دون بقايا أصناف أو فواتير اختبار.
- ربط الإنتاج اكتمل50 من50. عدد القيود6 وفرق المدين والدائن صفر، وبصمة كل سطور القيود لم تتغير أثناء الربط.
- الاختبار من واجهة موظف ومدير مالي بإدخال بيانات الدخول لم يكتمل بعد. لا تعتبر اختبار SQL المصادق أو واجهة المحاكاة بديلًا عنه.
