# قوالب د. دينا

1. في Supabase مشروع إنتاج المحتوى، شغّل `supabase/migrations/20261010_dina_design_templates.sql` في SQL Editor. لا يحذف مواد أو نسخ تصميم.
2. حدّث Edge Function المسماة `design-scene` من `supabase/functions/design-scene/index.ts` ثم Deploy updates. المفاتيح الموجودة تظل في Secrets.
3. بعد نشر GitHub Pages، حدّث الداشبورد. افتح مادة بوست صورة لصفحة د. دينا في مرحلة التصميم ثم إنشاء تصميم.
4. افتح القالب والترتيب ثم تنويعة التصميم. التنويعات ١–١٢ تطابق ترقيم الملفات المرسلة. ارفع الصورة أو اخترها من مكتبة د. دينا أو ولّد مشهدًا.
5. عدّل العنوان والسطر التوضيحي والدعوة للتفاعل. التنويعات ١–٥ تدعم أيضًا نصًا داخل التصميم. النصوص الأصلية للمنشور لا تُستبدل.
6. احفظ نسخة للمراجعة ثم أرسلها للاعتماد من مسار المادة المعتاد.

التصميم يصدر PNG بمقاس 1080×1350، ويستخدم Tajawal والخلفيات الأصلية. تحفظ التنويعة والنصوص والمواضع مع النسخة القابلة لإعادة الفتح. بيانات التواصل وصور د. دينا ثابتة داخل الخلفيات المرسلة؛ القوالب ١–٢ تحتوي رقم موبايل مختلفًا عن ٣–١٢. راجع الرقم قبل اعتماد الهوية نهائيًا.

الاختبارات: معاينة جميع التنويعات على الكمبيوتر والموبايل، حفظ واستعادة الإعدادات عبر نسخة الحساب بمحاكاة قاعدة البيانات، اختبار قوالب سونو عبر ستة أحجام شاشة، ومحاكاة التوليد والتوسيع والصلاحيات وإعادة الطلب بدون استدعاء مدفوع. التفعيل الفعلي في Supabase والتوليد المدفوع يحتاجان التجربة بعد النشر.
