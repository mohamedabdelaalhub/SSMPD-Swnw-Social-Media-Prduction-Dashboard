# توسيع خلفية الصورة

داخل استوديو التصميم: الصورة ← توسيع خلفية الصورة.

- كل الجهات: يترك مساحة حول الشخص لتصغيره داخل التصميم.
- يمين وشمال: يضيف خلفية جانبية للحركة الأفقية.
- تظهر نتيجة منفصلة للمراجعة. استخدام النتيجة يبدّل الصورة مع الحفاظ على النصوص والألوان والقالب.
- الرجوع للصورة قبل التوسيع يعمل خلال التعديل وبعد حفظ النسخة وإعادة فتحها. تحفظ الوظيفة الأصل في design-scenes الخاص، وتصدر رابطًا مؤقتًا بعد التحقق من حساب الموظف.
- كل توسيع يدخل في حدود reserve_design_scene الحالية. يحجز التوسيع جودة high باستخدام حجز التكلفة الحالي، دون تجاوز حد المحاولات أو الحد الشهري. الحجز تقديري وليس فاتورة فعلية.
- يحتفظ الطلب بمعرف لمنع تكراره عند استعادة نفس النتيجة. إلغاء نتيجة أو تغيير الصورة ينشئ طلبًا مختلفًا عند التوسيع التالي.
- ترسل الصورة الأصلية فقط. لا ترسل نص المنشور أو اللوجو أو بيانات التواصل إلى التوليد.

## التفعيل

1. افتح مشروع إنتاج المحتوى uuijfbpgvtdxgaosqpxo في Supabase.
2. Edge Functions ← design-scene ← Code.
3. استبدل index.ts بمحتوى supabase/functions/design-scene/index.ts في هذا المستودع، ثم Deploy updates.
4. حدّث الداشبورد وافتح الصورة ← توسيع خلفية الصورة.

لا يحتاج SQL جديدًا أو تغيير المفتاح. يستخدم OPENAI_API_KEY الموجود على السيرفر فقط. يعتمد الملف على npm:pngjs@7.0.0 لحماية البكسلات الأصلية بعد تحرير الخلفية. لا ترسل المفتاح إلى المتصفح.

## الاختبار

- tests/design-scene-expansion.cjs: API وهمي للتحرير والتوليد، حماية بكسلات الشخص الأصلية، حفظ الأصل، الصلاحيات، التحقق من الصور والقناع، وعدم تكرار الطلب. يحتاج pngjs@7.0.0.
- tests/design-expansion-ui.cjs: Chromium على الكمبيوتر والموبايل. مراجعة النتيجة وإلغاءها وتطبيقها والرجوع للأصل والحفظ وإعادة الفتح وأخطاء التوليد.
- tests/design-editor-responsive.cjs: مراجعة الأقسام والمعاينة والتصدير على ستة مقاسات شاشة.

لم يشمل الاختبار استدعاءً مدفوعًا أو نشرًا داخل Supabase. جودة استكمال الخلفية تحتاج تجربة صورة واحدة بعد التفعيل.
