# متابعة إنجاز الموظف

تظهر في الرئيسية الشخصية، وأدائي، وملف الموظف ضمن المهام والأداء. لا تغير مؤشرات أداء المحتوى القائمة. يمكن للموظف قراءة نفسه فقط، وللمدير العام والسوبر أدمن قراءة موظف آخر. امتلاك الموارد البشرية وحده لا يمنح بيانات مهام الآخرين.

## ما يُقاس

مؤشر إنجاز مهام من 100. اعتماد المهمة = 100، التسليم للمراجعة = 75 مؤقتًا، والمهمة المستحقة غير المسلمة = صفر. المتوسط لا يظهر بوصف أداء قبل 3 مهام. من 85 إنجاز رائع، ومن 60 إنجاز يتقدم، وأقل من 60 يحتاج انتباهًا. هذه حدود ثابتة معلنة في الشرح وليست تقديرًا للقدرة أو حكمًا وظيفيًا.

المؤشر يختص بالمهام، وليس جودة العمل بالكامل أو الحضور أو أداء المهنة. لا ينفذ جزاءات أو خصومات أو رسائل بريد أو قرارات توظيف. لا يُنشئ مهام تحسين مكررة. يفتح المهمة الأصلية للعمل والتسليم والمراجعة.

لا يُعد انتظار المدير تأخيرًا على الموظف. لا يمنح مجرد بدء العمل نقاطًا. المراحل الفرعية تُحسب دون تكرار المهمة الأم معها. تاريخ الالتزام يعتمد أول تسليم وموعده المسجل، ويعرض منفصلًا عن الإنجاز. اعتماد مهمة متأخرة يحسن الإنجاز، ولا يمحو سجل تأخرها.

## الفترة

اليوم وآخر 7 أيام والشهر الحالي وكل الفترة أو فترة يحددها المستخدم. الحدود من قاعدة البيانات بتوقيت Africa/Cairo، بما يشمل التوقيت الصيفي. نختار المهام المستحقة حتى نهاية الفترة، وما سُلّم أو اعتمد خلالها. للفترات التي تنتهي اليوم نضيف المتأخرات المفتوحة السابقة، مع عدّها وشرحها. الموعد المستقبلي غير المستحق لا يخفض الدرجة. المهمة بلا موعد تظهر في الخطة لتنظيمها، ولا تُحسب قبل التسليم أو الاعتماد.

الحالة هي آخر حالة مسجلة للمهام التي تخص الفترة، وليست لقطة تاريخية ثابتة. لا ندعي اتجاهًا تاريخيًا للدرجة دون بيانات لقطات. المهام المعتمدة من مشروع مؤرشف تبقى محسوبة، والعمل المفتوح بالمشروع المؤرشف يُستبعد.

## التحسين والتنبيه

تنبيه داخل الكارت يظهر عند انخفاض المؤشر، وليس نافذة توقف العمل. الخطة تعرض أول 8 مهام، مع العدد الكامل ورابط المهام، مرتبة بالعوائق ثم المطلوب تعديله ثم المتأخر فالقادم ثم ما بلا موعد ثم انتظار المراجع. كل خطوة تشرح الإجراء وتفتح أصل المهمة. ملاحظة المراجع ظاهرة للمهمة المعادة.

إعادة الحساب عند تغيير المهام أو اعتمادها في الجلسة، وعند تحديث بيانات الإشعارات الموجودة، أو فتح الصفحة بعد انتهاء التخزين المؤقت، أو الضغط على تحديث. لا يوجد polling ولا قناة realtime جديدة ولا استدعاء نموذج ذكاء اصطناعي. رد الخادم ملخص وعدد محدود من الخطوات، ولا يحمّل سجل مهام الفريق للموظف.

## التحقق

- tests/employee-performance-sql.cjs يشغّل SQL الفعلي بمحاكاة PostgreSQL ويختبر الحساب والصلاحيات.
- tests/employee-performance-dom.cjs يختبر التنبيه والخطة والتحديث وعزل الحسابات والطلبات المشتركة والنصوص.
- tests/employee-performance-fixture.html معاينة مستقلة ببيانات محاكاة دون طلب API أو اعتماد مهام حقيقية.
- اختبارات تنظيم الموارد البشرية وتكامل الدخول والصورة تبقى مطلوبة عند الدمج.

فحص قاعدة الإنتاج للقراءة فقط أثبت نطاق الموظف ومنع طلب بيانات موظف آخر وسماح المدير وغياب EXECUTE عن anon. فحص advisors لا يذكر الدالة في مشكلة search_path أو anon. يذكرها ضمن التنبيه العام للدوال SECURITY DEFINER المتاحة للمستخدم المسجل؛ إبقاؤها مقصود مع فحص auth.uid والحساب النشط وصلاحية المهام والموظف المستهدف، واختبارات رفض الوصول. لا تمنح الدالة أي صلاحيات كتابة.
