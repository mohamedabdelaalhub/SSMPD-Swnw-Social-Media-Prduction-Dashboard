# تقرير مقارنة استمارات التخاطب وتعديل السلوك وتنمية المهارات

قورنت استمارات د لينا الحسين المرفقة بواجهة ملف المريض وقاعدة البيانات في 17 أكتوبر 2026. التغيير يضيف البنود الناقصة إلى التخاطب وينشئ استمارتي تعديل السلوك وتنمية المهارات داخل أرشيف المرضى. لا ينقل بيانات حالة إلى حالة أخرى ولا يستبدل السجلات الحالية.

## نتيجة المقارنة

| الاستمارة | الموجود قبل التعديل | الإضافة |
|---|---|---|
| التخاطب واللغة | تقييم أولي وسجل جلسات | استكمال التقييم الموجود بالحقول والمقاييس والخطة التفصيلية الواردة بالملف |
| تعديل السلوك | وسم سلوك ضمن مشكلات الصحة النفسية وحقول شكوى وهدف وملاحظات عامة | استمارة مستقلة تشمل جميع أسئلة تعديل السلوك وجدول الملاحظة وخطة المتابعة |
| تنمية المهارات | لا توجد استمارة أو جدول مخصص لها | استمارة مستقلة تشمل مجالات المهارات وملاحظات التقييم والخطة والتوصيات |

## التخاطب واللغة

| البند في الاستمارة المرفقة | قبل التعديل | ما تغير |
|---|---|---|
| اسم الطفل وعمره | موجودان ببيانات المريض | يُعرضان في التقييم ويمكن الاحتفاظ بقيمتهما داخل الاستمارة وقت التقييم |
| تاريخ الميلاد وتاريخ التقييم وولي الأمر ووسيلة التواصل واللغة أو اللهجة المنزلية | لا توجد حقول لها في تقييم التخاطب | أضيفت داخل نفس التقييم. تاريخ التقييم منفصل عن تاريخ أول جلسة |
| مشكلات السمع أو اختبار السمع | غير موجود كبند مستقل | أضيف حقل مستقل |
| ظهور أول كلمة وأول جملة | موجودان | الاحتفاظ بالحقلين والقيم المسجلة دون إنشاء نسخة ثانية منهما |
| التاريخ الطبي أو النمائي | توجد حقول للحمل والولادة والوراثة فقط | أضيف حقل تاريخ طبي أو نمائي عام مع الإبقاء على التفاصيل القديمة |
| جلسات التخاطب السابقة وتفاصيلها | موجودان | الاحتفاظ بهما في نفس موضع الحفظ |
| مهارات التواصل واللغة | حقل نصي عام لمستوى الفهم والكلام | الاحتفاظ بالنص العام وإضافة 9 بنود، لكل بند تقييم وملاحظات |
| ملاحظات النطق | لا توجد حقول تفصيلية | أضيفت الأصوات والحروف المطلوب تقييمها وأمثلة نطق الطفل |
| الخطة والمتابعة | هدف عام وسجل جلسات يحتوي أهدافًا وتدريبًا وواجبًا منزليًا وموعدًا تاليًا | الإبقاء عليها وإضافة خطة التقييم المكونة من الهدف والنشاط وإرشادات المنزل وموعد المتابعة |
| التوصيات أو التقييم الإضافي | ملاحظات عامة فقط | أضيف حقل مستقل للتوصيات، ومنها السمع واللغة |
| توقيع الأخصائية وولي الأمر | غير موجودين | أضيفت خانات تدوين الاسم أو وصف التوقيع الوارد بالاستمارة. لا تُعد هذه الخانات خدمة توقيع إلكتروني |
| العبارة الخاصة بكون الاستمارة أداة تنظيمية وليست تشخيصًا مستقلًا | غير موجودة | أُضيف نصها |

بنود التواصل التسعة هي الانتباه للصوت والاسم، وفهم التعليمات، وفهم المفردات والأسئلة، واستخدام الكلمات والجمل، والتعبير عن الاحتياجات، والتواصل البصري والانتباه المشترك، وتبادل الأدوار والحوار، ووضوح الكلام ومخارج الأصوات، والطلاقة وإيقاع الكلام.

خيارات كل بند هي مناسب للعمر، ويحتاج دعمًا، ولم يُقيّم. يمكن ترك البند دون اختيار ولا يُفترض تقييم من تلقاء النظام.

احتُفظ أيضًا بنوع المشكلة، ووقت بدايتها، وزواج الأقارب، والتاريخ الوراثي وتفاصيله، ومشكلات الحمل والولادة وتفاصيلها، وعدد الجلسات المخطط لها، وملاحظات الأخصائي، وسجل الجلسات والحضور والاستجابة. هذه حقول سابقة لم تطلب الاستمارة حذفها.

## تعديل السلوك

أضيفت بيانات الطفل والعمر وتاريخ التقييم والمدرسة أو الحضانة والصف وولي الأمر ووسيلة التواصل وسبب التحويل أو الشكوى. تُملأ بواسطة ولي الأمر أو الأخصائية وفق النص المرفق.

أضيفت البنود الثمانية التالية. لكل بند اختيار نادرًا أو أحيانًا أو غالبًا وحقل ملاحظات.

1. فرط الحركة وصعوبة الجلوس
2. تشتت الانتباه
3. رفض التعليمات أو عدم إكمال المهام
4. نوبات غضب أو صراخ
5. ضرب أو إيذاء الآخرين
6. إلقاء الأشياء أو إتلافها
7. الاندفاع أو المقاطعة أو صعوبة انتظار الدور
8. سلوك آخر مع حقل لوصفه

أضيفت أسئلة وقت ومكان ظهور السلوك، وما يسبقه، واستجابة المحيطين، وما يساعد على التهدئة. وأضيفت اهتمامات الطفل ومكافآته والمهارات التي يتقنها.

خطة المتابعة تتكون من الهدف السلوكي وطريقة التدريب أو التعزيز وموعد المراجعة. تبدأ بثلاثة صفوف كما في المصدر ويمكن إضافة أهداف أو إزالة صف أثناء تحرير الاستمارة. تليها توصيات الأسرة أو المدرسة وخانتا توقيع الأخصائية وولي الأمر.

وسم سلوك السابق في الصحة النفسية لا يمثل هذه الاستمارة. ظل قسم الصحة النفسية وبياناته دون استبدال أو نسخ تلقائي لبياناته داخل النموذج الجديد.

## تنمية المهارات

أضيفت بيانات الطفل والعمر أو تاريخ الميلاد وتاريخ التقييم وولي الأمر ووسيلة التواصل والمدرسة أو الحضانة والصف.

أضيفت المجالات الأحد عشر التالية. لكل مجال اختيار مستقل أو بمساعدة أو يحتاج تدريبًا وحقل ملاحظات.

1. الانتباه والتركيز
2. اتباع التعليمات
3. المهارات الحركية الدقيقة مثل مسك القلم والقص
4. المهارات الحركية الكبرى مثل القفز والتوازن
5. التآزر البصري الحركي
6. الإدراك البصري والتمييز
7. التصنيف والمطابقة والتسلسل
8. الذاكرة وحل المشكلات
9. التواصل والتفاعل الاجتماعي
10. الاعتماد على النفس
11. الاستعداد الأكاديمي وما قبل المدرسة

أضيفت نقاط القوة والمهارات التي تحتاج إلى تنمية واهتمامات الطفل أو المعززات. والخطة تتكون من المهارة المستهدفة والنشاط أو التدريب ومستوى المساعدة ومتابعة التقدم. تبدأ بثلاثة صفوف ويمكن زيادتها. تليها توصيات المنزل وخانتا توقيع الأخصائية وولي الأمر.

## الحفظ والصلاحيات

- استُكمل سجل تقييم التخاطب القائم. الحقول المطابقة تستخدم الأعمدة السابقة، والحقول الإضافية تحفظ معه دون حذفها عند تحرير الحقول القديمة.
- تعديل السلوك وتنمية المهارات يظهران داخل ملف المريض. يمكن حفظ أكثر من تقييم مؤرخ لكل استمارة وعرضه أو تعديله لاحقًا.
- يحفظ الخادم هوية المنشئ والمعدّل والتواريخ. تعديل تقييم قائم لا يغيّر صاحب الإنشاء ولا يسمح بنقله إلى مريض آخر.
- صلاحية الأرشيف الكاملة تتيح الإضافة والتعديل. صلاحية مراجعة الأرشيف تتيح القراءة. لا تُضاف النماذج تلقائيًا لبوابة المريض.
- لا تظهر استمارة فارغة على أنها تقييم محفوظ. تعذر قراءة استمارة يُعرض كخطأ ولا يُعامل كسجل غير موجود.
- جرى تصحيح إعادة تحميل بيانات التخاطب والصحة النفسية بعد حفظ ملف المريض.

## التحقق

نجحت اختبارات محلية لعدد بنود النماذج 9 و8 و11، وخياراتها، وصفوف الخطط، وحفظ واسترجاع القيم، وعرض القراءة فقط، ومنع تفسير النص ككود، والإبقاء على بيانات التخاطب السابقة وصاحب إنشائها بعد الحفظ وإعادة الفتح.

نجحت اختبارات قاعدة اختبار محلية للترحيل الإضافي وإعادة تطبيقه، والإبقاء على بيانات التخاطب الموجودة، وصلاحيات القراءة والكتابة ومنع المستخدم غير المصرح، وتسجيل المنشئ والمعدل، ومنع تغيير مريض التقييم أو نوعه. ونجحت اختبارات الداشبورد العامة وروابط بروفايلات المرضى وكروت الرئيسية.

اختبار الواجهة بحساب مستخدم على الإنتاج لم يُنفذ في هذه الجلسة. جلسة المتصفح المتاحة تعرض صفحة الدخول. اختبارات التفاعل المذكورة تستخدم بيانات اختبار، ولا تثبت مراجعة الشكل البصري على هاتف حقيقي.
