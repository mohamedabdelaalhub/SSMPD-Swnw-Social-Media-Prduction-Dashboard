# استيراد تعريفات المستلزمات والأدوية

من الحسابات ← التسعير والخدمات والباكجز ← المستلزمات والإضافات الطبية ← رفع مستلزمات وأدوية Excel.
ينشئ هذا المسار صنف مخزون وتعريف تسعير مرتبطًا بنفس الصنف بمعامل صرف1 للوحدة الصغرى. يحتاج صلاحية إدارة المخزن وصلاحية الإضافة بالحسابات معًا.

ومن الحسابات ← المخازن والجرد ← المخزون ← الأصناف والأسعار ← رفع أصناف Excel يمكن استيراد تعريفات المخزون فقط، بصلاحية إدارة المخزن.

1. نزّل النموذج. أدخل الأصناف في الورقة الأولى، حتى500 صنف و5 ميجابايت. يدعمxlsx وxls وcsv. حوّل المعادلات لقيم قبل الرفع.
2. لا تدخل كود الصنف. الخادم يولد ITM عند الإضافة ويحتفظ بالأكواد القديمة. تسلسل الأكواد قد يتضمن فجوات بعد عملية متراجعة.
3. اختر الوحدة الصغرى مثل قرص، والكبرى مثل علبة، والعدد مثل20. الرصيد والصرف يظلان بوحدة القرص. سعر الكبرى = سعر الصغرى × العدد.
4. سعر الشراء الاسترشادي قبل الربح لا يسجل شراء أو رصيدًا أو مستحق مورد. عند الاستيراد للتسعير يلزم هذا السعر لتكوين تكلفة العبوة التعريفية. سعر الشراء الفعلي يسجل بفاتورة الاستلام المعتادة، ويظل حساب البيع من أعلى شراء فعلي والهامش كما كان.
5. ترك الهامش فارغًا يستخدم الهامش الموحّد إن أُعد، وإلا0. إدخال0 صراحة يعني هامشًا خاصًا0. ترك سعر البيع فارغًا يحسبه من الشراء الاسترشادي والهامش. إدخال سعر بيع صريح يعني السعر بعد الربح.
6. راجع المعاينة. زر تعديل يغير مسودة السطر فقط. حذف من المعاينة لا يحذف أي صنف محفوظ. تكرار الاسم ووحدة الصرف أو وجود خطأ يمنع إضافة الكل. عند مسار التسعير يمنع أيضًا تكرار اسم مستلزم التسعير.
7. إضافة الكل تحفظ الدفعة في معاملة واحدة. الخطأ يعيد الدفعة بالكامل، ويبقي المعاينة للتصحيح. إعادة المحاولة بنفس الرمز والمحتوى لا تكرر الإضافة. لا يُرفع الملف نفسه للتخزين.

في إضافة صنف بالمخزون الكود للعرض فقط. تظهر الوحدة الكبرى وسعر شرائها الاسترشادي وسعر بيعها المحسوب من الصغرى. يحسب إدخال الشراء الاسترشادي سعر البيع بالهامش قبل وجود شراء فعلي. بعد وجود شراء فعلي لا يحل الاسترشادي محله. تغيير عدد الوحدات أو وحدة الصرف ممنوع بعد الطلبات أو الحركات أو الربط بالتسعير لحماية التحويلات القائمة.

## التنفيذ والتحقق

المصدر `20261018003127_inventory_catalog_bulk_units.sql`. أسعار الشراء الاسترشادية وسجل إعادة الطلبات في جداولclinic_finance خاصة ذاتRLS ومن دون منح وصول مباشر. snapshot يعرض السعر الاسترشادي لمسؤول إدارة المخزن فقط. الأكواد يولدها trigger بخادم البيانات لجميع طرق إنشاء أصناف المخزون، ولا تعتمد على عداد المتصفح. لا تعديل كميات أو تشغيلات أو حساب مورد أو قيود مالية في استيراد التعريفات.

`tests/inventory-catalog-bulk-sql.cjs` يراجعSQL الجديدة عبرPGlite مع حدود اعتماد سابقة ممثلة في fixture. `tests/inventory-catalog-live-rollback.sql` يتحقق من المسار الحالي الحقيقي داخلrollback بما فيه الربط والتكلفة وعدم إنشاء حركة مخزون أو فاتورة. لا يغير أدوار موظفين ولا يحفظ بيانات اختبار.

`tests/inventory-catalog-bulk-ui.cjs` يراجع الواجهة أمام بيانات محاكاة عند1280/390/320، مع عدم الحفظ قبل التأكيد والتعديل والحذف والخطأ وإعادة المحاولة والتحويلات. افتراضيًا يستخدم قارئ اختبار لعزل تدفق الواجهة. تعيينXLSX_QA_SCRIPT إلى مكتبةSheetJS0.18.5 المستخدمة أصلًا فيindex يختبر ملفxlsx فعليًا من إنشائه حتى قراءته. نُفّذ الاختبار بالطريقتين، مع الصور للمراجعة محليًا. لا يدعي اختبار حساب موظف مسجل.
